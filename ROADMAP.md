# Roadmap

## v1.0.0 (Current) — Production Baseline

First production-ready release. Security hardening, reliability fixes, code quality
improvements, comprehensive testing, and documentation.

See [CHANGELOG.md](CHANGELOG.md) for the full list of changes.

## v1.1 (Next) — Plugin Ecosystem

- [ ] Subprocess-based plugin sandboxing (user plugins run in isolated processes)
- [ ] Plugin marketplace / discovery mechanism
- [ ] Plugin developer CLI tooling
- [ ] More built-in plugins (Zotero integration, PDF annotation)
- [ ] Plugin hot-reload without app restart

## v1.2 — Collaboration

- [ ] Multi-user support (shared research groups)
- [ ] Shared paper libraries with access control
- [ ] Annotation and comment threads on papers

## v2.0 — Cloud Sync

- [ ] Optional encrypted cloud sync across devices
- [ ] Mobile companion app (read-only paper browsing)
- [ ] API versioning (`/api/v2/`)
- [ ] gRPC or WebSocket-based real-time collaboration

## Ongoing

- Performance optimization (large paper libraries, fast search)
- Accessibility improvements
- Community building and contributor onboarding
